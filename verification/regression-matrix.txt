The installer selects nt/ or w32s/ files by platform at run time; the shell

Uninstall results: Program Manager group / Desktop+Programs shortcuts, all
installed payload files and the registry entries are removed on every OS; user
files are preserved. NT 3.1/3.51/4 and Windows 95 remove the installation
directory completely. On Win32s the uninstaller runs in place (no hang) and
best-effort deletes its own image; the uninstaller executable and its directory
may remain because a loaded Win32s module cannot delete itself and Windows 3.1
has no delayed-delete mechanism.
